The 6-step method for any new problem

  1. 1

    Understand

    Restate it in your words. Ask about input size, empty input, duplicates, negatives.

  2. 2

    Examples

    Solve one normal case and one edge case by hand.

  3. 3

    Brute force

    Say the simplest correct idea and its Big-O out loud.

  4. 4

    Pattern

    Look for signals. Name the pattern and why it fits.

  5. 5

    Code

    Write it cleanly. Narrate what each block does.

  6. 6

    Test & analyze

    Dry-run your example. State time and space, with a reason.

Typing code is step 5, not step 1.

Live example: Two Sum

Given an array nums and a number target, return the indices of the two numbers that add up to target.
nums = [3, 8, 4, 6, 1], target = 10  →  [2, 3]

Step 1: questions I'd ask

Is there always exactly one answer?
Can I use the same element twice?
Is the array sorted?

Step 4: signals

"pair" + unsorted + must return indices.
Sorting would lose the indices.

Better question: "Have I already seen my partner?"

Step 3: brute force first

function twoSum(nums, target) {  for (let i = 0; i < nums.length; i++) {    for (let j = i + 1; j < nums.length; j++) {      if (nums[i] + nums[j] === target) return [i, j];    }  }  return [];}

Check every pair.

Time O(n²)
Space O(1)

Correct, but 100,000 numbers means about 5 billion checks.

Can we find the partner without a second loop?

Step 4: remember what you've seen

target = 10For each number, ask: is my partner already in the map?

7 is not in the map. Store 3 → 0.

i = 1, value 8. Partner = 2.
Not in the map. Store 8 → 1.

i = 2, value 4. Partner = 6.
Not in the map. Store 4 → 2.

i = 3, value 6. Partner = 4.
4 is in the map at index 2. Return [2, 3].

One pass. Each map lookup is O(1).
Total: O(n) time.

Steps 5 and 6: code it, then prove it

function twoSum(nums, target) {  const seen = new Map(); // value -> index  for (let i = 0; i < nums.length; i++) {    const partner = target - nums[i];    if (seen.has(partner)) return [seen.get(partner), i];    seen.set(nums[i], i);  }  return [];} console.log(twoSum([3, 8, 4, 6, 1], 10)); // [2, 3]
ApproachTimeSpace
Brute forceO(n²)O(1)
Hash mapO(n)O(n)

We spent memory to save time. Same trade-off as prefix sums.

Think out loud: what to actually say

While understanding

"Let me restate the problem to check I've got it…"

Before optimizing

"A simple approach is checking every pair. That's O(n²)."

Spotting the pattern

"It asks for a pair and isn't sorted, so I'll use a map."

While coding

"This map stores value to index so I can find the partner in O(1)."

Testing

"Let me dry-run [3, 8, 4, 6, 1] with target 10…"

Finishing

"Time is O(n): one pass. Space is O(n): the map."

Problem 1: Contains Duplicate Warm-up

Return true if any value appears at least twice in nums, otherwise false.
[1, 2, 3, 1] → true
[1, 2, 3, 4] → false

Hint 1. At each number, what question do you ask?

Hint 2. "Have I seen this before?" Which structure answers that in O(1)?

function containsDuplicate(nums) {  const seen = new Set();  for (const n of nums) {    if (seen.has(n)) return true;    seen.add(n);  }  return false;}

Hash set: O(n) time, O(n) space. Sorting first: O(n log n) time.

Problem 2: Best Time to Buy and Sell Stock

prices[i] is the price on day i. Buy once, sell once later. Return the maximum profit, or 0.
[7, 1, 5, 3, 6, 4] → 5  (buy at 1, sell at 6)

Hint 1. Brute force tries every buy/sell pair. What's that Big-O?

Hint 2. Walking left to right, what one thing should you remember about the past?

Hint 3. The cheapest price so far. Today's profit = price − minSoFar.

function maxProfit(prices) {  let minPrice = Infinity, best = 0;  for (const p of prices) {    minPrice = Math.min(minPrice, p);    best = Math.max(best, p - minPrice);  }  return best;}

One pass, two variables: O(n) time, O(1) space.

Problem 3: Move Zeroes

Move all 0s to the end in place, keeping the order of the other numbers.
[0, 1, 0, 3, 12] → [1, 3, 12, 0, 0]

Hint 1. "In place" means no new array. Which pattern fits?

Hint 2. Two pointers: read scans everything, write marks the next spot for a non-zero.

function moveZeroes(nums) {  let write = 0;  for (let read = 0; read < nums.length; read++) {    if (nums[read] !== 0) {      [nums[write], nums[read]] = [nums[read], nums[write]];      write++;    }  }  return nums;}

O(n) time, O(1) space. Each element is read once.
